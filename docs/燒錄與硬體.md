# 燒錄與硬體

> 設定請先做完：改 `firmware/staffroom_config.h` → 跑 `py -X utf8 tools/apply_config.py`。
> 那一步會產生 `firmware/*/config.h`，沒有它就編不過。

---

## 1. 三塊板子

| 角色 | 板子 | 連線 | 電源 |
|---|---|---|---|
| **門口機** Door | Waveshare ESP32-S3-Touch-LCD-7B（1024×600、GT911 觸控） | USB-C（**CDCOnBoot 要關**，見下） | 5 V / ≥2 A |
| **語音機** Audio | ESP32-S3 **N16R8**（16 MB flash、8 MB OPI PSRAM） | USB-C（CDC 開） | 5 V / ≥2 A |
| **矩陣屏** Matrix | ESP32-S3 **N32R16**（32 MB flash、16 MB OPI PSRAM） | USB-C（CDC 開） | **面板要獨立 5 V / ≥4 A** |

⚠️ **三塊板子的 PSRAM 都是 OPI（八線）**，不是 QSPI。這個選錯會直接開不了機。

⚠️ 矩陣屏的 P5 面板**絕對不要**從開發板的 5 V 腳拉電，一定要獨立供電、
共地就好。從板子拉電會造成重開機，運氣不好會燒掉穩壓器。

## 2. 語音機接線（唯一需要自己接的）

兩組 SPI/I2S 裝置：

```
ESP32-S3 N16R8                     microSD 模組          PCM5102A DAC
──────────────                     ────────────          ────────────
GPIO 10  ────────────────────────  CS
GPIO 12  ────────────────────────  SCK / CLK
GPIO 13  ────────────────────────  MISO / DO
GPIO 11  ────────────────────────  MOSI / DI
3V3      ────────────────────────  VCC
GND      ────────────────────────  GND

GPIO  5  ───────────────────────────────────────────────  BCK
GPIO  6  ────────────────────────────────  LRCK
GPIO  7  ─────────────────────────────────────────────────  DIN
3V3      ────────────────────────────────────────────────  VIN
GND      ────────────────────────────────────────────────  GND
                                                          OUTL/R → 有源喇叭
```

**這是最常見失敗的地方。** 幾個一定要知道的：

- **有源喇叭（自帶電源的）**才可以直接接 DAC 的輸出。被動喇叭要另外接放大器。
- PCM5102A 模組上的 **SCK 腳要接地**（很多模組板上已經處理好了，看一下）。
- 第一次測試**先把音量轉到最小**，播完再調。DAC 滿刻度輸出會很吵。
- microSD 模組如果是 5 V 版，要確認它有 3.3 V 穩壓；直接餵 3.3 V 給 5 V 模組不會動。

⚠️ **擴充板 / 開發板不同，腳位就不同。** 說明書裡 `-1` 是「還沒填」的意思，
填完真正的號碼、接線確認過之後，才把 `AUDIO_PINS_CONFIRMED` 改成 `true`。
維持 `false` 的話語音機不會初始化 SD 與 I2S —— 這是刻意的，避免亂填腳位把板子弄壞。

工具會擋掉這幾類腳位：GPIO 0 / 3 / 45 / 46（strapping）、19 / 20（USB）、
26~37（被 OPI PSRAM 佔用）、43 / 44（UART）。

## 3. Arduino IDE 設定

1. **開發板管理器網址**（檔案 → 偏好設定）：
   `https://espressif.github.io/arduino-esp32/package_esp32_index.json`
2. **開發板管理器**安裝 **esp32 by Espressif**，版本選 **3.3.7**。
   （`3.3.x` 之外沒測過；ESP-IDF 的 API 在 3.x 有變動。）
3. **函式庫管理器**安裝：
   - **ArduinoJson 7.4.3**（音訊機與門口機都要）
   - Adafruit **GFX** 與 **BusIO**（只有矩陣屏需要）

## 4. 開哪個資料夾、選什麼板子

三個 `.ino` 是三個獨立 sketch。**開資料夾，不是開檔案**：

| 開這個資料夾 | 選這個開發板設定 |
|---|---|
| `firmware/Door` | **ESP32S3 Dev Module**<br>Flash 16 MB · PSRAM **OPI PSRAM** · Partition **app3M_fat9M_16MB** · **USB CDC On Boot：停用** |
| `firmware/Audio` | **ESP32S3 Dev Module**<br>Flash 16 MB · PSRAM **OPI PSRAM** · Partition **app3M_fat9M_16MB** · USB CDC On Boot：啟用 |
| `firmware/Matrix` | **ESP32S3 Dev Module**<br>Flash **32 MB** · PSRAM **OPI PSRAM** · Partition **app5M_fat24M_32MB** · USB CDC On Boot：啟用 |
| `firmware/NetworkCheck` | 同 Audio（只是診斷用的小程式） |

> **門口機的「USB CDC On Boot」一定要停用。** 那塊板子的 USB 是走原生 USB-JTAG，
> 打開 CDC 會跟 LCD 的初始化打架，串口反而看不到東西。

用 arduino-cli 的話，對應的 FQBN：

```bash
# 門口機
esp32:esp32:esp32s3:FlashSize=16M,PSRAM=opi,PartitionScheme=app3M_fat9M_16MB,CDCOnBoot=default
# 語音機 / NetworkCheck
esp32:esp32:esp32s3:FlashSize=16M,PSRAM=opi,PartitionScheme=app3M_fat9M_16MB,CDCOnBoot=cdc
# 矩陣屏
esp32:esp32:esp32s3:FlashSize=32M,PSRAM=opi,PartitionScheme=app5M_fat24M_32MB,CDCOnBoot=cdc
```

```bash
arduino-cli compile --fqbn <上面的 FQBN> firmware/Door
arduino-cli upload  --fqbn <上面的 FQBN> -p COM8 firmware/Door
```

## 5. 建議的點亮順序

**不要三塊一起上電。** 一次只驗證一件事，出錯才知道是誰。

### ① 語音機：先確認卡和喇叭

1. SD 卡照 `sd_templates/AUDIO/` 的結構放好（`students.csv` / `teachers.csv` 在根目錄，
   錄音放 `students/`、`teachers/`）。
2. 把 `AUDIO_TEST_STAGE` 設成 **1**，燒錄，看串口：
   應該印出 `WAV /teachers/01.wav PASS` 之類的每一項。
3. 全部 PASS 之後改成 **2**，再燒一次。這次會**播一次**就停，且不連 Wi-Fi。
   音量先關小。
4. 聽到了 → 改回 **0**（正式模式），再燒一次。

### ② 門口機：先看畫面

燒錄 `firmware/Door`，接電。應該看到：
- 開機動畫（welcome 滑動）
- 首頁：數字鍵盤 +「網路設定」按鈕

如果畫面全黑但串口有輸出 → 背光或排線問題；
如果觸控沒反應 → GT911 的 I2C 腳位問題（這塊板子是原廠固定的，正常不會錯）。

### ③ 兩塊一起：確認叫號

1. 語音機上電，等它開機完成（串口會印 `AUDIO SETUP Staffroom-XXXX-Audio at 192.168.4.1`）。
2. 門口機上電。它會自己去連那個熱點，畫面頂端會顯示 **`192.168.4.x`**。
   - 沒連上就按「網路設定」→ 輸入 PIN → 按 **「改用熱點叫號」**。
3. 回首頁，輸入一組**名冊裡真的有**的 5 位學號，按確認。
   應該聽到「○○○老師」→「△△△同學找」。

### ④ 矩陣屏（可選，最後做）

1. **先不要用本專案的程式。** 用原廠 `01_SimpleTestShapes` 範例點亮面板，
   確認掃描方式（1/8 還是 1/16）與驅動 IC（SHIFTREG 還是 FM6126A）。
2. 確認之後才回來改 `staffroom_config.h`：
   `PANEL_CONFIRMED = true`，必要時 `PANEL_FM6126A` / `PANEL_CLKPHASE` 也調。
3. `PANEL_BRIGHTNESS` 第一次請保持 32，看清楚再往上加。

## 6. 燒成單一 .bin（給不想裝 Arduino 的人）

編譯完之後，可以用 esptool 把 4 個檔案合併成一個，之後只要一行指令就能燒：

```bash
esptool --chip esp32s3 merge_bin -o Door.bin \
  --flash_mode dio --flash_freq 80m --flash_size 16MB \
  0x0     bootloader.bin \
  0x8000  partitions.bin \
  0xe000  boot_app0.bin \
  0x10000 Door.ino.bin
```

燒錄：

```bash
esptool --chip esp32s3 -p COM8 -b 921600 write_flash 0x0 Door.bin
```

這些 `*.bin` 在 Arduino 的建置暫存目錄裡（開啟「顯示詳細輸出」可以看到路徑），
arduino-cli 用 `--build-path` 指定一個資料夾比較好找。

## 7. 卡住了先看這裡

| 症狀 | 先檢查 |
|---|---|
| 編譯說找不到 `config.h` | 還沒跑 `py -X utf8 tools/apply_config.py` |
| 編譯說 `WIFI_SSID` 未定義 | 同上 |
| 編譯過但一上電就重開 | PSRAM 沒選 OPI、或 partition scheme 選錯 |
| 串口完全沒輸出（門口機） | USB CDC On Boot 要**停用** |
| 畫面是黑的但串口正常 | 背光 / 排線；確認是 7B 不是 7 |
| 語音機 `sd_mount_failed` | SD 模組接線、卡是 FAT32、卡有插好 |
| 語音機說 `AUDIO_PINS_CONFIRMED` 相關 | `staffroom_config.h` 那項還是 `false` |
| 叫號沒聲音但畫面正常 | WAV 格式：PCM 16-bit、16000 或 22050 Hz、≤30 秒 |
| 名字顯示成空白（不是問號） | 名冊改了但沒重跑 `tools/generate_fonts.py` |
| 門口機連不上語音機 | 門口機有沒有拿到 `192.168.4.x`；按「改用熱點叫號」 |
| 兩套系統互相干擾 | `SYSTEM_ID` 重複了，兩套要取不同名字 |
